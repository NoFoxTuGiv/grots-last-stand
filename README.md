# Grot's Last Stand

A Warhammer 40k Space Invaders clone built in GoDot that attempts to emulate the looks and feel of a class GameBoy game. Fend off waves of White Scar Marines and survive as long as you can, racking up a high score.

![Screenshot](/assets/MockUp.png)

## Keyboard Instructions
Move Left:
- A
- Left Arrow

Move Right:
- D
- Right Arrow

Shoot:
- Space
- Enter

Controller compatability is also in place, left to go left, right to go right, and any button or trigger shoots

## Specifications
- 160 x 144 base resolution (defaulted to 800 x 720)
- Original GameBoy inspired color palette and graphics
    - Source: [Kirokaze on Lospec](https://lospec.com/palette-list/kirokaze-gameboy)
